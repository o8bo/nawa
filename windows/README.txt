Nawa 0.3.1 for Windows 10/11 (64-bit)

Extract the entire ZIP first, then open Nawa.exe.
Keep the _internal folder beside Nawa.exe. Python and GTK are included.
Choose Settings to switch Arabic / English and SAR / USD.

Your data and preferences are in %LOCALAPPDATA%\Nawa.
The installer and portable build use the same data folder.
Uninstalling the program leaves this folder intact.

Reminders appear inside Nawa while it is running. Closing the last window
exits Nawa and stops reminders. This build does not use the Linux system tray.

Source, license and updates: https://github.com/o8bo/nawa
The Windows binaries are not digitally signed.
